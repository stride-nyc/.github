# Stride NYC

We're a technology and digital transformation consultancy.

## Sharing AI Practices

We share our agentic skills, prompts, and AI practices with each other — and with the community. Each person maintains their own repos; this org is a clearinghouse of pointers.

Browse the [Skills Registry](https://github.com/stride-nyc/.github/tree/main/skills-registry/people) to see what people are building and sharing.

Want to add your own? See the [contribution guide](https://github.com/stride-nyc/.github/blob/main/skills-registry/PERSON_TEMPLATE.md).

## Plugin Marketplace

We maintain a shared plugin registry for Claude Code. To add it:

```sh
/plugin marketplace add stride-nyc/stride-plugins-official
```

Browse and install plugins interactively with `/plugin > Discover`, or install directly:

```sh
/plugin install pdca-framework
/plugin install pdca-scaffold
```
